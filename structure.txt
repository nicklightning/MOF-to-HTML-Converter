Baseline Page Creator
|   LICENSE.md										# License information. 
|   requirements.txt								# Python package and installation information. 
|   structure.txt									# Description of file and folder structure. 
|   File Addresses.env								# Open and edit this using a text editor such as Notepad. Defines URL addresses to be used for generic information about assessments. Also, the names of files and folders that the user can set. 
|   xml MOF renamer.py								# Run this 1st. Reads the folder (from "File Addresses.env") in which XML versions of MOFs are available, then re-names each file with the module code that applies to it.
|   xlsx MOF renamer.py								# Run this 2nd. Reads the folder (from "File Addresses.env") in which XLSX versions of MOFs are available, then re-names each file with the module code that applies to it.  
|   Module Data Aggregator.py						# Run this 3rd. Reads the folder (from "File Addresses.env") in which XML versions of MOFs are available, collates all the data into a convenient, readable XLSX file (output filename can be defined in .env file).  
|   Module Assessment Page Creator.py				# Run this 4th. Reads the aggregated module data file (as generated by "Module Data Aggregator.py") and generates HTML pages about each module's assessments. Reads URL's used for links from the "File Addresses.env" file.  
|   Module Information Page Creator.py				# Run this 5th. Reads the folder (from "File Addresses.env") in which XLSX versions of MOFs are available, reads XLSX versions of MOFs and generates HTML pages about each module's Aims, Syllabus Outline, Knowledge Outcomes and Skills Outcomes. 
|   Initialise Module Contacts.py					# Run this 6th. Reads the aggregated module data file (as generated by "Module Data Aggregator.py"), and generates an output.xlsx file containing the names of staff who contribute to modules. Do not change or re-format the names that feature in columns A and B! You should manually populate this file (cols C and D) with office addresses and other contact details, the resulting file will be needed by Module Contacts Installer.py. 
|   Module Contacts Page Creator.py					# Run this 7th. You must use the .env file to specify the name of the input file to be used as a source of module contact information! This input file must be in the same format as the output file generated by the "Initialise_Module_Contacts.py" file.  
|   
+---MOF Files
|   +---XLSX MOFs									# For each module that you wish to generate pages for, you will need to download the ".xlsx" version of the MOF from the university's module catalogue and place it inside this folder. A file re-naming utility that labels each file with the correct module code is provided for convenience (see above).  
|   \---XML MOFs									# For each module that you wish to generate pages for, you will need to download the ".xml" version of the MOF from the university's module catalogue and place it inside this folder. A file re-naming utility that labels each file with the correct module code is provided for convenience (see above). 
+---Templates
|       assessment_overview_main.html				# Template for "module assessment" pages. You can tweak the text as you wish but don't change the html formatting or the "final_html_body" and "footer" instructions unless you really know what you are doing.
|       module_contacts_template.html				# Template for "module contacts" pages. You can tweak the text as you wish but don't change the html formatting or the "content" and "footer" instructions unless you really know what you are doing. 
|       alternate_module_contacts_template.html		# Template for "module contacts photo" pages. You can tweak the text as you wish but don't change the html formatting or the "content" and "footer" instructions unless you really know what you are doing. 
|       blue_button_template.html					# Template for the blue button links. If you know what you are doing, you could create an alternative design of blue button if you wish. 
|       coursework_template.html*					# Template for page to be linked from the "Further Information about Coursework" blue button.  
|       digital_exam_template.html*					# Template for page to be linked from the "Further Information about Digital Exams" blue button.  
|       take_home_template.html*					# Template for page to be linked from the "Further Information about Take-Home Exams" blue button.
|       written_exam_instructions.html*				# Template for page to be linked from the "Further Information about Written Exams" blue button.
|       
\---.venv

*Pages indicated by an asterisk allow the rapid generation of pages that provide generic information about each of the different types 
of assessment. You do not have to use these if you have alternative pages available that will serve the same purpose. Anyway, locate your generic information pages 
at URLs where they can be accessed by all of your intended audience- for example, within a Canvas Course School Canvas Community that is accessible by *all* of your 
intended audience. Then, write the URLs for each of the pages you've created into the "File Addresses.env" file before running the programs shown above.
