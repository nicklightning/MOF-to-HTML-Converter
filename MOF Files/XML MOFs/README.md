
Deposit module outline forms in ".xml" format in this folder. 

These can be obtained from Newcastle University's module form database <https://apps.ncl.ac.uk/MOFS/Module> by; 
	(i) Select "Reports" in the top menu; 
	(ii) Enter the module code and current academic year, then "View Report"; 
	(iii) Click on the icon that looks like a floppy disk. Click the option that says "XML file with report data"; 
	(iv) The file you download (the module outline form in .xml format) will go into your "Downloads" folder by default. 

Eventually- you will need to have a file called "[module code].xlm" within this folder for every module for which you are generating an html page. 

I recommend that you start by just downloading all the forms you need into your "Downloads" folder (don't take the time time to re-name them as you go). 

Then, move all of your downloaded MOFs (all those which are xml files) into this folder. 

You can then run the "xml MOF renamer.py" program and it will re-name them all for you as required.
